# Vale a Dois — pacote completo para o Codex

1. Extraia este ZIP na pasta de trabalho do Codex com o repositório VALE-2 selecionado.
2. Envie: **“Leia 00_COMECE_AQUI.md e VALE_A_DOIS_DOCUMENTO_MESTRE.md. Implemente o pacote no jogo atual, seguindo os marcos e preservando os saves.”**
3. Para ler com imagens no navegador, abra `LEITURA.html` mantendo a pasta `arte` ao lado.

O documento mestre já reúne os capítulos. Os arquivos separados facilitam trabalho por assunto. `conteudo/historia.json` contém missões e diálogos; `sistemas.json` contém valores de design; `arte_manifesto.json` identifica as cinco pranchas. Esses dados não são código pronto para executar.

As imagens são conceitos completos de direção visual. Os atlases finais de animação precisam ser produzidos e validados pelo Codex conforme o catálogo. Não há alterações no repositório feitas por este pacote. APK e multiplayer seguem fora do escopo.

Arquivos de desenvolvimento não devem ser confundidos com a exigência de distribuição: o jogo entregue ao usuário deve continuar sendo um único index.html autocontido.
